# Sistema-de-irriga-o-inteligente-de-Natally-Caroliny-Silva-e-Natallya-Cristina-Silva
A irrigação inteligente utiliza sensores para monitorar a umidade do solo e controlar automaticamente a liberação de água conforme a necessidade das plantas. Essa tecnologia evita desperdícios, reduz custos e facilita o cuidado com as plantações, promovendo uma agricultura mais eficiente, prática e sustentável.
